# Quiz_CLI
It is a simple quiz cli made using python 

It has been made using mysql 

where there is a register as admin as well as student is added 

there are questions which can only be added or removed or updated by admin 

admin can see anyone's marks

there is a password required to register as admin but anyone can register as student

student can see their marks after finishing test
